# Laboratorio 10 - Manejo de carpetas y ficheros con interfaz gráfica en Python

Este laboratorio forma parte del repositorio central [Curso - Sistemas Operativos](https://github.com/Jose01R/Curso-Sistemas-Operativos) y corresponde a una práctica académica de programación en Python centrada en la gestión de archivos y carpetas mediante una interfaz gráfica.

## Descripción

El proyecto tiene como objetivo practicar el manejo de archivos y directorios en Python, usando la función `open()` y sus modos de apertura para leer, escribir y actualizar contenido en archivos nuevos o existentes. Además, se implementa una interfaz gráfica con Tkinter para facilitar la interacción con el usuario.

## Temas tratados

- Manipulación de archivos en Python.
- Uso de `open()` con modos de lectura, escritura y actualización.
- Lectura, escritura y borrado de archivos.
- Manejo de rutas y directorios.
- Creación y organización de carpetas.
- Exploración de archivos en un sistema de directorios.
- Búsqueda de archivos por extensión o patrón.
- Visualización de propiedades de archivos.
- Desarrollo de interfaces gráficas con Tkinter.
- Diseño de menús y formularios en aplicaciones GUI.
- Programación modular en Python.

## Objetivo del laboratorio

- Comprender cómo funcionan los archivos en un sistema operativo.
- Aprender a leer y escribir información en archivos de texto.
- Practicar el uso de rutas, carpetas y búsquedas de archivos.
- Desarrollar una pequeña aplicación con interfaz gráfica para gestionar archivos.
- Aplicar conceptos básicos de entrada/salida y organización de datos.

## Tecnologías utilizadas

- Python
- Tkinter
- pathlib
- os
- Archivos de texto
- Interfaces gráficas de usuario

## Requisitos

Para ejecutar este proyecto necesitas:

- Python 3 instalado.
- Tkinter disponible en tu entorno.
- Un sistema operativo compatible (Linux, Windows o macOS).

## Ejecución

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Jose01R/Laboratorio-No.-10---Manejo-de-carpetas-y-ficheros-con-interfaz-gr-fica-en-Python.git
   ```

2. Entra a la carpeta del proyecto:

   ```bash
   cd Laboratorio-No.-10---Manejo-de-carpetas-y-ficheros-con-interfaz-gr-fica-en-Python
   ```

3. Ejecuta la aplicación principal:

   ```bash
   python main.py
   ```

## Funcionalidades principales

- Gestión de archivos.
- Apertura de archivos desde el sistema.
- Guardado y guardado como.
- Eliminación de archivos.
- Limpieza del contenido mostrado.
- Gestión de carpetas.
- Búsqueda de archivos por patrón.
- Consulta de propiedades de archivos.
- Menú principal con accesos a cada módulo.
